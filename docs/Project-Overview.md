# 🚀 Project Overview

## Problem Statement

Telecom Network Operations Centers (NOC) often rely on manual processes for incident triage, ticket creation, and escalation.

These repetitive tasks increase response time and delay incident resolution.

---

## Solution

AI Ticket Automation leverages Generative AI and workflow automation to intelligently process telecom incidents and automate the complete ticket lifecycle.

---

## Features

✔ AI Incident Classification

✔ Automatic Severity Detection

✔ Root Cause Analysis

✔ Priority Assignment

✔ Jira Ticket Automation

✔ Google Sheets Logging

✔ Email Notifications

✔ Dashboard Integration
